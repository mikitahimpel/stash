# stash

Collect links and open tabs from every device into one AI-organized, searchable stash — with a Claude MCP connector.

It runs at **https://stash.mikitahimpel.com**: the web app, the api under `/api`, and the MCP server at `https://stash.mikitahimpel.com/mcp` (add that URL to Claude as a custom connector). Only the owner can sign in.

See [docs/architecture.md](docs/architecture.md) for the design and [docs/deploy.md](docs/deploy.md) for deploying your own.
